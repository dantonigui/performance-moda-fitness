# Performance Moda Fitness — Link in Bio

A mobile-friendly link page that helps customers reach Performance Moda Fitness through WhatsApp and browse its product catalog.

## Highlights

- Direct WhatsApp contact.
- Link to the product catalog.
- Brand imagery and responsive layout.

## Built with

- HTML5 and CSS3
- Google Fonts: Bricolage Grotesque
- Bootstrap Icons

## Live site

[performance-coral.vercel.app](https://performance-coral.vercel.app)

## Run locally

Open `index.html` in a browser. No build step is required; fonts and icons are loaded from external CDNs.
