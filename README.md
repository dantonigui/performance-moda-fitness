# Performance | Moda Fitness — Link in Bio

Página de links da Performance Moda Fitness, com acesso direto ao WhatsApp e ao catálogo de produtos.

## Links

- WhatsApp — contato direto
- Catálogo — via Canva

## Tecnologias

- HTML5 e CSS3
- Google Fonts (Bricolage Grotesque)
- Bootstrap Icons

## Estrutura

```
/
├── index.html
├── style.css
├── teste.png
└── icon.jpeg
```

## Como rodar

Abra o `index.html` no navegador. Não há dependências para instalar — fontes e ícones são carregados via CDN.

## Adicionar novos links

Insira um novo `<li>` dentro da `<ul>` no `index.html`:

```html
<li>
  <a href="URL">Nome do link <i class="bi bi-nome-do-icone"></i></a>
</li>
```

Ícones disponíveis em [icons.getbootstrap.com](https://icons.getbootstrap.com/).
